Denne app har flere dele: Den fuldt tilpasselige Advanced Virtual Device, Flow Exchange(r) og en liste af unikke flowkort.

Advanced Virtual Device (AVD).

Opret en enhed og konfigurer den selv:
* Tekstlig status, som du kan vælge som statusindikator på enhedens flise i mobilappen, indstilles gennem flows.
* Tilpassede uploadede ikoner kan indstilles som kapabilitetsikon.
* Lad enhedens flise fungere som en push-knap (forbliver lys/mørk efter klik) men indstil mørk/lys på flisen som status fra et flow.
* Ubegrænsede numre, tekst, ja/nej'er, knapper, lister og kameraer kan tilføjes.
* Skjul enhedens fliseknap fra selve enheden.
* Brug API'en til at opdatere eller ændre felter eller AVD'er.
* Chronographs og Better Logic Library Variabler kan direkte afspejles på AVD-felter uden flows.
* Og meget, meget mere!

Se emnerne på community-forumet for eksempler eller hjælp.

Flow Exchange(r).

Eksporter og importer Flows og/eller Advanced Virtual Devices fra andre Homey-brugere.
Importer via skabeloner via appindstillinger, AVD-reparation eller når du opretter AVD'er.

Flowkort.

Der er flere unikke flowkort, f.eks. for at hente brugeren og klienten, når en enhed tændes/slukkes eller en værdi ændres, eller når en app er startet.
Eller brug flowkort til at reagere, når værdierne for enheder ændres, for hvilke der ikke er (egne) flowkort.
Eller hent indsigt fra x minutter siden.
Og hvad angår værdier, der er en specifik værdi i længere tid end en bestemt periode.

Se community-forumet for mere information!

Denne app kan forbinde til andre apps som Better Logic Library og Chronograph.
