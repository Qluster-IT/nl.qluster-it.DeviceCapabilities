Diese App besteht aus mehreren Teilen: dem vollständig anpassbaren Advanced Virtual Device, dem Flow Exchange(r) und einer Liste einzigartiger Flowcards.

Advanced Virtual Device (AVD).

Erstellen und konfigurieren Sie ein Gerät selbst:
* Wählen Sie als Statusanzeige auf der Gerätkachel in der mobilen App einen Textstatus, der über Flows einstellbar ist.
* Eigene hochladbare Symbole können als Fähigkeitensymbol festgelegt werden.
* Lassen Sie die Gerätkachel als Tastknopf funktionieren (bleibt hell/dunkel nach dem Klicken), stellen Sie aber Dunkel/Hell auf der Kachel als Status über einen Flow ein.
* Unbegrenzte Anzahl von Zahlen, Texten, Ja/Nein-Buttons, Listen und Kameras kann hinzugefügt werden.
* Verstecken Sie die Gerätekachel-Schaltfläche vom Gerät selbst.
* Nutzen Sie die API, um die Felder oder AVDs zu aktualisieren oder zu ändern.
* Chronographen und Variablen der Better Logic Library können direkt in AVD-Feldern ohne Flows angezeigt werden.
* Und vieles, vieles mehr!

Sieh dir die Themen im Community-Forum für Beispiele oder Hilfe an.

Der Flow Exchange(r).

Flows und/oder erweiterte virtuelle Geräte von anderen Homey-Nutzern exportieren und importieren.
Importieren Sie über Vorlagen über App-Einstellungen, AVD-Reparatur oder beim Erstellen von AVDs.

Flowcards.

Es gibt mehrere einzigartige Flowcards, z.B. um Benutzer und Client abzurufen, wenn ein Gerät ein-/ausgeschaltet wird oder sich ein Wert ändert, oder wenn eine App gestartet wurde.
Oder verwende Flowcards, um zu reagieren, wenn sich Werte von Geräten ändern, für die es keine (eigenen) Flowcards gibt.
Oder rufe Einblicke von x Minuten zuvor ab.
Und was ist, wenn Werte länger als eine bestimmte Zeit einen bestimmten Wert haben.

Sieh dir das Community-Forum für weitere Informationen an!

Diese App kann mit anderen Apps wie der Better Logic Library und Chronograph verbunden werden.
