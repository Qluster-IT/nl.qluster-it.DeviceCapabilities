새로운 기능: AVD 필드 업데이트를 위한 API 호출.

새로운 기능: 다른 Homey 사용자로부터 Flows 및/또는 고급 가상 장치(AVD)의 내보내기 및 가져오기.
앱 설정, AVD 수리 또는 AVD 생성 시 템플릿을 통해 가져오기 가능.

또한 새로운 기능: 완전 맞춤형 가상 장치(AVD)!
예제는 설명을 참조하세요.

장치를 생성하고 직접 구성하세요:
* 모바일 앱의 장치 타일에서 상태 지표로 선택할 수 있는 텍스트 상태, 흐름을 통해 설정 가능합니다.
* 사용자 정의 업로드 가능한 아이콘을 기능 아이콘으로 설정할 수 있습니다.
* 장치 타일이 푸시 버튼으로 작동할 수 있습니다(클릭 후 밝게/어둡게 유지), 하지만 흐름에서 타일의 밝기/어둡기를 상태로 설정합니다.
* 10개의 숫자, 텍스트, 예/아니오, 버튼 및 카메라를 장치 추가 가능.
* 장치 자체에서 장치 타일 버튼 숨기기.

그리고

특정 분 전(현재는 영 제로일 수도 있음)의 사용자 및 클라이언트 데이터를 통찰력에서 검색하기 위한 흐름카드.
예: 30분 전의 LivingRoom에서 온도 값을 검색합니다.

또는

기기의 기능을 구역별로 설정하여 특정 구역의 모든 커튼을 여닫거나(하위 구역 포함 또는 제외) 특정 브랜드나 장치 유형의 기능을 설정할 수 있습니다.
앱 개발자의 트리거가 없는 기능에 대해서도 유저 및 클라이언트(App)가 기능 값을 변경했을 때 토큰을 제공합니다.
그리고 특정 "오류"를 기다리는 조건을 통해 기능을 설정할 수 있습니다.

또한 새로운 액션카드가 추가되었습니다. 이는 [numberof] 분 전의 기기 기능 값을 검색합니다(값을 변경한 유저 및 클라이언트 포함).

그리고 앱이 시작된 카드(When)와 앱이 실행 중인 카드(And).

예제: 커튼.windowcoverings_set 값을 포함하기(예) 하위 구역(예)에서 0으로 설정합니다.
이렇게 하면 집과 하위 구역의 모든 커튼이 닫힙니다. 1로 설정하면 모든 커튼이 열립니다.

예제: Vacuumcleaner1에서 bin_full 감시(청취)
장치 이름이 Vacuumcleaner1인 장치의 bin_full 용량이 변경되면 흐름이 트리거됩니다.
값을 확인하여 빈이 가득 찼을 때 휴대폰으로 알림을 보내세요.

예제: SamsungFrameTV.onof를 True로 설정하고 오류 대기: 이미 전원이 켜졌습니다...
TV가 켜지면 흐름이 계속 진행됩니다. 따라서 더 이상 TV나 커피메이커가 켜지길 기다리며 지연되는 흐름은 없습니다.

예제: 여전히 30분 전의 LivingRoom에서 온도 값을 검색하세요.
