이 앱은 여러 부분으로 구성되어 있습니다: 완전히 맞춤화 가능한 고급 가상 장치, Flow Exchange® 및 고유한 플로우 카드 목록입니다.

고급 가상 장치 (AVD).

스스로 장치를 만들고 구성하세요:
* 모바일 앱의 장치 타일에서 상태 표시기로 선택할 수 있는 문자 상태, 플로우를 통해 설정 가능합니다.
* 맞춤 업로드 아이콘을 기능 아이콘으로 설정할 수 있습니다.
* 장치 타일이 푸시 버튼으로 작동하게 하면서 (클릭 후 밝기/어둠 상태를 유지) 플로우로 타일의 어둡기/밝기 상태를 설정하세요.
* 무제한 숫자, 텍스트, 예/아니오, 버튼, 목록 및 카메라를 추가할 수 있습니다.
* 장치 자체에서 장치 타일 버튼 숨기기.
* API를 사용하여 필드나 AVD를 업데이트하거나 변경하세요.
* 연대기 및 Better Logic Library 변수를 플로우 없이 AVD 필드에 직접 반영할 수 있습니다.
* 그리고 훨씬 더 많은 기능들이 있습니다!

예제나 도움을 위해 커뮤니티 포럼의 주제를 참조하세요.

Flow Exchange®

다른 Homey 사용자로부터 플로우 및/또는 고급 가상 장치를 내보내고 가져오세요.
앱 설정, AVD 복구 또는 AVD 생성 시 템플릿을 통해 가져오기 가능합니다.

플로우 카드.

여러 고유한 플로우 카드가 있으며, 예를 들어 장치가 켜지거나 꺼질 때 사용자와 클라이언트를 가져오거나 값이 변경되었을 때, 또는 앱이 시작되었을 때 반응하는 플로우 카드가 있습니다.
또는 장치 값이 변할 때 반응하도록 하는 플로우 카드를 사용하세요. 자체 플로우 카드가 없는 경우에도 사용할 수 있습니다.
X분 전의 인사이트 가져오기.
특정 값이 일정 시간 이상 유지될 때에 대한 반응도 가능합니다.

더 많은 정보는 커뮤니티 포럼을 참조하세요!
