Это приложение включает в себя несколько частей: Полностью настраиваемое Расширенное Виртуальное Устройство, Обмен потоками(r) и список уникальных карточек потоков.

Расширенное Виртуальное Устройство (AVD).

Создайте устройство и настройте его сами:
* Текстовый статус, который можно выбрать в качестве индикатора статуса на плитке устройства в мобильном приложении, устанавливается через потоки.
* Загружаемые настраиваемые иконки могут быть установлены в качестве иконки функции.
* Плитка устройства может функционировать как кнопка (оставаясь светлой/темной после нажатия), но устанавливайте темный/светлый на плитке как статус из потока.
* Можно добавить неограниченное количество чисел, текстов, да/нет, кнопок, списков и камер.
* Скрывайте кнопку на плитке устройства самого себя.
* Используйте API для обновления или изменения полей или AVD.
* Хронографы и переменные библиотеки Better Logic могут напрямую отображаться на полях AVD без потоков.
* И многое другое!

Смотрите темы на форуме сообщества для примеров или помощи.

Обмен потоками(r).

Экспортируйте и импортируйте потоки и/или Расширенные Виртуальные Устройства от других пользователей Homey.
Импортируйте через шаблоны через настройки приложения, ремонт AVD или при создании AVD.

Карточки потоков.

Есть несколько уникальных карточек потоков, например, для получения пользователя и клиента, когда устройство включается/выключается или изменяется значение, или когда приложение запущено.
Или используйте карточки потоков для реакции при изменении значений устройств, для которых нет (собственных) карточек потоков.
Или получите информацию из x минут назад.
И что для значений, которые остаются специфическими дольше определенного периода.

Смотрите форум сообщества для получения дополнительной информации!

Это приложение может подключаться к другим приложениям, таким как библиотека Better Logic и хронограф.
