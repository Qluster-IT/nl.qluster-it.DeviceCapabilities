This app has multiple parts: The fully customisable Advanced Virtual Device, The Flow Exchange(r) and a list of unique flowcards.


Advanced Virtual Device (AVD).

Create a device and configure it yourself:
* Textual Status which you can select as Status Indicator on the Device Tile in Mobile App, setable through flows.
* Custom uploadable icons can be set as capability icon.
* Have the Device Tile function as a Pushbutton (staying light/dark after clicked) but set Dark/Light on the Tile as status from a flow.
* unlimited Numbers, Texts, Yes/No's, Buttons, Lists and Cameras can be added.
* Hide device tile button from the device itself.
* Use the API to update or change the fields or AVD's.
* Chronographs and Better Logic Library Variables can be directly reflected on AVD fields without flows.
* And much, much more!

See the topics on the community forum for examples or help.


The Flow Exchange(r).

Export and import Flows and/or Advanced Virtual Devices from other Homey users.
Import via Templates via App Settings, AVD Repair or when creating AVDs.


Flowcards.

There are multiple unique flowcards, f.i. to retrieve the User and Client for when a device is turned on/off or a value changed, or for when an app has started.
Or use flowcards to react when values of devices change, for which there are no (own) flowcards.
Or Retrieve Insights from x minutes ago.
And whats for values being a specific value for longer than a certain period.

See the community forum for more information!

This app can connect to other apps like the Better Logic Library and Chronograph.
