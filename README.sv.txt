Den här appen har flera delar: Den helt anpassningsbara Advanced Virtual Device, Flow Exchange(r) och en lista över unika flödeskort.

Advanced Virtual Device (AVD).

Skapa en enhet och konfigurera den själv:
* Textstatus som du kan välja som statusindikator på enhetsskärmen i mobilappen, inställbar via flöden.
* Anpassningsbara ikoner kan laddas upp och ställas in som kapabilitetsikon.
* Låt enhetsskärmen fungera som en tryckknapp (behåller ljus/mörk efter klick) men ställ in mörk/ljus på skärmen som status från ett flöde.
* Obegränsat antal nummer, texter, ja/nej, knappar, listor och kameror kan läggas till.
* Dölj enhetens skärmknapp från själva enheten.
* Använd API:n för att uppdatera eller ändra fälten eller AVD:erna.
* Kronografer och variabler i Better Logic Library kan direkt återspeglas på AVD-fält utan flöden.
* Och mycket, mycket mer!

Se ämnena på communityforumet för exempel eller hjälp.

The Flow Exchange(r).

Exportera och importera flöden och/eller Advanced Virtual Devices från andra Homey-användare.
Importera via mallar i appinställningar, AVD-reparation eller när du skapar AVD:er.

Flödeskort.

Det finns flera unika flödeskort, t.ex. för att hämta användare och klient när en enhet slås på/av eller ett värde ändras, eller för när en app har startat.
Eller använd flödeskort för att reagera när enheters värden ändras, för vilka det inte finns några (egna) flödeskort.
Eller hämta insikter från x minuter sedan.
Och vad gäller värden som har en viss värde längre än en viss period.

Se communityforumet för mer information!

Denna app kan anslutas till andra appar som Better Logic Library och Chronograph.
